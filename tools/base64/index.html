파일 → Base64

이미지·문서 파일을 선택하면 Base64(Data URL)로 변환합니다. 브라우저에서만 처리되며 서버로 전송되지 않아요.

Base64는 암호화가 아닙니다. 비밀번호·주민번호 같은 민감 정보는 인코딩만으로 보호되지 않아요. 매우 큰 파일은 브라우저 메모리 부담이 있을 수 있습니다.

HOW IT WORKS

Base64란?

바이너리 데이터를 텍스트로 안전하게 담기 위한 인코딩 방식이에요.

Base64는 바이너리 데이터를 텍스트(문자열) 형태로 안전하게 전달하기 위해 쓰는 인코딩 방식입니다. 예를 들어 이메일·JSON·로그 등에 이미지나 파일 데이터를 포함해야 할 때 Base64를 사용해요.

  • API 요청·응답에 바이너리 데이터를 문자열로 담아야 할 때
  • JWT 헤더·페이로드처럼 Base64URL 기반 포맷을 이해할 때
  • 디버깅 중 "이 문자열이 Base64인지" 빠르게 확인할 때

Base64는 암호화가 아니므로 보안 목적이라면 반드시 별도의 암호화·서명 방식을 사용해야 해요.

GOOD TO KNOW

궁금한 점이 있나요?

Base64 인코더·디코더에 대해 자주 묻는 질문을 모았어요.

입력한 텍스트/파일이 서버로 전송되나요?

아니요. 모든 인코딩·디코딩은 브라우저에서만 수행되며, 입력 내용이나 파일은 서버로 전송되거나 저장되지 않습니다.

Base64는 암호화인가요?

아닙니다. Base64는 단지 데이터를 텍스트로 표현하는 인코딩 방식입니다. 누구나 쉽게 디코딩할 수 있으므로 비밀번호·개인정보 보호 용도로는 적합하지 않습니다.

한글이 깨지지 않나요?

이 도구는 UTF-8 기준으로 인코딩·디코딩하도록 처리하여 한글·이모지도 정상 변환됩니다. (단, 외부에서 잘못 인코딩된 Base64 문자열은 원문이 깨질 수 있습니다.)
