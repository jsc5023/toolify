🔐 chmod 권한 계산기

숫자 권한과 문자 권한을 실시간으로 변환하고, SUID·SGID·Sticky까지 한 번에 확인해요.

755 → -rwxr-xr-x

특수 권한 (선택)

특수값 0

SUID/SGID는 실행 위치에 s/S, Sticky는 others 실행 위치에 t/T로 표시됩니다.

입력값은 이 브라우저에서만 계산되며 저장되지 않습니다.

HOW IT WORKS

chmod 권한은 어떻게 계산하나요?

읽기(4)·쓰기(2)·실행(1)을 더해 소유자·그룹·기타 권한을 만들어요.

리눅스 파일 권한은 소유자(user)·그룹(group)·기타(others) 세 그룹에 각각 읽기·쓰기·실행 권한을 부여하는 방식이에요. 각 권한에는 숫자값이 있어서 더하면 하나의 숫자로 표현할 수 있습니다.

권한 숫자 = 읽기(4) + 쓰기(2) + 실행(1)

숫자 권한(755)을 입력하면 문자 권한(-rwxr-xr-x)으로, 반대로 문자 권한을 입력하면 숫자로 즉시 변환됩니다. 4자리 숫자(예: 4755, 1777)를 입력하면 SUID·SGID·Sticky 특수권한까지 함께 반영돼요.

텍스트를 다른 형식으로 변환하고 싶다면 Base64 변환기나 URL 인코더도 확인해보세요.

GOOD TO KNOW

궁금한 점이 있나요?

chmod 권한 계산기에 대해 자주 묻는 질문을 모았어요.

chmod 755는 어떤 권한인가요?

소유자(rwx=7), 그룹(r-x=5), 기타(r-x=5) 권한으로 -rwxr-xr-x에 해당합니다.

SUID/SGID/Sticky는 어떻게 표현되나요?

4자리 숫자 권한(예: 4755, 2755, 1777)으로 표현되며, 문자 권한에서는 실행 위치에 s/S, t/T로 표시됩니다.
