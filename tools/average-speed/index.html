HOW IT WORKS

여러 구간 평균속도 계산기란?

여러 이동 구간의 거리와 시간을 합쳐 여행 전체의 실제 평균속도를 계산하는 도구예요.

평균속도 계산 방법

각 구간 속도의 평균이 아니라 모든 구간의 이동거리를 더하고, 모든 이동시간을 더한 뒤 나눕니다.

전체 평균속도 = 전체 이동거리 ÷ 전체 이동시간

이 도구에서 평균속도는 이동거리 ÷ 경과시간으로 계산하는 평균 속력의 의미로 사용합니다. 방향이나 변위는 계산하지 않아요.

왜 속도를 그냥 평균내면 안 될까요?

100km를 100km/h로 이동하면 1시간, 다시 100km를 50km/h로 이동하면 2시간이 걸립니다. 단순 평균은 75km/h지만 실제로는 200km를 3시간 동안 이동했으므로 약 66.67km/h예요.

200km ÷ 3시간 = 약 66.67km/h

GOOD TO KNOW

궁금한 점이 있나요?

여러 구간 속도 계산에서 자주 묻는 내용을 모았어요.

여러 구간의 평균속도는 어떻게 계산하나요?

각 구간의 거리를 모두 더한 뒤 각 구간의 이동시간을 모두 더해 나눕니다.

구간별 속도를 그냥 평균내면 안 되나요?

구간마다 거리나 시간이 다르면 단순 평균은 실제 전체 평균과 달라질 수 있습니다. 오른쪽 결과에서 두 값을 함께 비교할 수 있어요.

휴식이나 정차시간도 포함할 수 있나요?

네. 구간 목록 아래 정차·휴식 시간을 입력하면 이동 평균과 정차 포함 전체 평균을 구분해 보여줍니다.

시간 입력과 속도 입력을 섞어도 되나요?

네. 각 구간마다 입력 방식을 독립적으로 선택할 수 있으며 내부에서는 모두 거리와 초 단위 시간으로 통일해 계산합니다.

평균속도와 순간속도는 무엇이 다른가요?

평균속도는 전체 이동거리와 전체 시간으로 계산한 값이고, 순간속도는 특정 순간의 계기판 속도처럼 그 시점의 빠르기입니다.
