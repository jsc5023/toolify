HOW IT WORKS

여러 날짜 간격 계산기란?

두 날짜만 비교하는 대신 날짜를 계속 추가해 모든 인접 구간을 한 화면에서 비교하는 도구예요.

사용 방법

  1. 첫 번째 날짜와 다음 날짜를 입력합니다.
  2. 필요한 만큼 날짜를 추가하고 메모를 적습니다.
  3. 각 구간의 일수와 오른쪽 전체 결과를 확인합니다.
  4. 필요하면 시작일 포함·평일·주말 보기를 켭니다.

날짜순 정렬은 버튼을 눌렀을 때만 실행되며, 같은 날짜는 기존 입력 순서를 유지해요.

날짜 계산 기준

기본값은 시작일을 제외한 달력 날짜의 차이입니다. 시작일 포함을 켜면 같은 날짜는 1일, 9월 1일부터 2일은 2일로 계산해요.

다음 날짜 − 이전 날짜 = 구간 간격

평일·주말 보기를 켜면 월요일부터 금요일은 평일, 토·일요일은 주말로 나누어 보여줍니다. 공휴일은 별도로 제외하지 않아요.

GOOD TO KNOW

궁금한 점이 있나요?

여러 날짜를 계산할 때 자주 묻는 질문을 모았어요.

같은 날짜를 입력하면 어떻게 계산되나요?

같은 날짜도 삭제하지 않고 각각 유지합니다. 기본 설정에서는 0일, 시작일 포함 설정에서는 1일로 계산해요.

중간에 빈 날짜가 있으면 어떻게 되나요?

빈 행은 구간을 끊는 경계가 됩니다. 빈 행 앞뒤의 날짜를 건너뛰어 새 구간으로 연결하지 않아요.

날짜 순서가 뒤바뀌어 있어도 계산되나요?

네. 입력 순서를 그대로 유지하고 앞 날짜보다 빠른 날짜에는 며칠 빠른지 안내합니다. 평균·최장·최단 통계는 절대 간격을 사용해요.

평일·주말 보기에서 공휴일은 어떻게 처리되나요?

공휴일 데이터를 사용하지 않고 월~금요일은 평일, 토·일요일은 주말로 나누어 계산합니다. 그래서 월~금에 있는 공휴일도 평일에 포함될 수 있어요.
