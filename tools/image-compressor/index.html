HOW IT WORKS

이미지 압축기가 필요한 순간

웹에 올리기 좋은 수준으로 사진 용량을 줄이는 원리예요.

이럴 때 사용해 보세요

요즘 스마트폰과 카메라로 찍은 사진은 한 장에 몇 MB씩 하는 경우가 많습니다. 블로그, 스마트스토어, 포트폴리오 사이트에 그대로 업로드하면 페이지 로딩 속도가 느려지고, 검색 노출에도 악영향을 줄 수 있습니다.

  • 블로그 글에 넣을 사진 용량을 줄이고 싶을 때
  • 스마트스토어·쿠팡 상품 상세 이미지가 너무 무거울 때
  • 포트폴리오 사이트/이력서 PDF에 넣을 이미지 최적화가 필요할 때
  • 메일 첨부 용량 제한 때문에 사진 크기를 줄여야 할 때

같은 80%라도 사진의 노이즈·색상·원본 형식에 따라 결과 용량과 눈에 보이는 차이가 달라집니다. 먼저 한 장으로 시험한 뒤 글자 가장자리와 그라데이션을 확대해 확인하세요.

선택한 이미지는 서버로 전송하지 않고 브라우저 메모리에서 읽어 압축합니다. 페이지를 새로고침하면 작업 목록도 사라집니다.

GOOD TO KNOW

궁금한 점이 있나요?

이미지 압축기에 대해 자주 묻는 질문을 모았어요.

이미지 품질(화질) 80%면 많이 떨어지나요?

일반적인 블로그·웹용 이미지에서는 75~85% 구간이 눈에 띄는 화질 손실 없이 용량을 크게 줄이는 구간으로 많이 사용됩니다. 아주 세밀한 그래픽 작업물이 아니라면 80% 전후에서 압축했을 때 대부분의 환경에서 충분히 깔끔하게 보입니다.

가로·세로 크기는 꼭 줄여야 하나요?

꼭 줄일 필요는 없지만, 스마트폰 원본 사진처럼 3000px 이상인 이미지를 그대로 올리면 용량이 매우 커집니다. 보통 웹에서는 긴 변 기준 1280~1920px 정도면 충분한 경우가 많으니, 상황에 맞게 최대 가로·세로 크기를 지정해 주면 용량을 더 많이 줄일 수 있습니다.

PNG를 JPG로 바꾸면 뭐가 좋은가요?

PNG는 배경이 투명하거나, 선명한 아이콘·로고에 적합하지만 사진에는 오히려 용량이 더 커지는 경우가 많습니다. 일반적인 사진은 JPG로 저장하는 편이 용량 면에서 훨씬 유리합니다. 투명 배경이 꼭 필요한 이미지가 아니라면 PNG → JPG 변환을 추천드립니다.

내 이미지가 서버에 저장되나요?

아니요. 이 도구는 브라우저 안에서만 동작합니다. 이미지를 서버로 업로드하지 않고, 내 PC(브라우저) 안에서만 압축·변환을 수행한 뒤 결과 파일을 내려받게 만드는 방식입니다.
