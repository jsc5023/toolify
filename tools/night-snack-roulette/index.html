HOW IT WORKS

야식도 조건을 먼저 좁혀보세요

늦은 시간엔 배달이 되는지, 혼자 먹기 좋은지가 특히 중요해요.

왜 조건부터 고르나요

야식은 시간이 늦을수록 선택지가 좁아집니다. 혼자 먹을 수 있는 양인지, 배달이 되는 가게가 남아 있는지, 속이 편한 가벼운 메뉴인지 등 실제로는 여러 조건이 걸려 있습니다. 그래서 이 룰렛은 완전 무작위 대신 조건 선택 → 룰렛 → 결과 흐름을 따릅니다.

필터는 혼자 먹기, 매운맛 제외, 든든하게, 가볍게, 새벽에도 OK 5가지이며 동시에 여러 개를 켤 수 있습니다. 예를 들어 '혼자 먹기'와 '새벽에도 OK'를 함께 켜면 늦은 시간에도 혼자 먹기 좋은 메뉴만 남습니다.

GOOD TO KNOW

궁금한 점이 있나요?

야식 메뉴 룰렛에 대해 자주 묻는 질문을 모았어요.

야식 메뉴는 몇 가지이고 어떻게 분류되나요?

치킨·피자 7개, 분식 9개, 면·밥 11개, 고기 10개, 매운 음식 5개, 간단·패스트푸드 10개, 디저트 8개로 총 60가지 야식 메뉴를 기본 제공합니다.

필터는 어떻게 작동하나요?

혼자 먹기·매운맛 제외·든든하게·가볍게·새벽에도 OK 5개 필터를 여러 개 동시에 켤 수 있습니다. 예를 들어 '혼자 먹기'와 '가볍게'를 함께 켜면 두 조건을 모두 만족하는 메뉴만 룰렛에 남습니다.

직접 추가한 메뉴도 결과에 나오나요?

네. 입력창에 메뉴 이름을 추가하면 목록에 카드로 추가되고, 필터와 상관없이 항상 룰렛 후보에 포함됩니다. 브라우저에 저장되어 다음에 방문해도 유지됩니다.

결과가 서버에 저장되나요?

아니요. 필터 선택과 메뉴 선택 상태는 현재 브라우저의 localStorage에만 저장되며 서버로 전송하지 않습니다.
