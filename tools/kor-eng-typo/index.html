HOW IT WORKS

한영타 실수를 빠르게 복구하는 방법

자동 감지가 어색한 경우에는 변환 방향을 직접 정해 결과를 확인할 수 있어요.

사용 방법

  1. 잘못 입력한 문장을 왼쪽 입력창에 붙여넣습니다.
  2. 자동 감지 결과를 확인하거나 영→한·한→영 모드를 고릅니다.
  3. 오른쪽 결과를 확인한 뒤 필요한 곳에 복사합니다.

변환 기준

두벌식(표준) 키보드 배열을 기준으로 한글과 영문 키 입력을 서로 바꿉니다. 숫자, 공백, 특수문자는 바꾸지 않고 Shift가 섞인 패턴도 가능한 범위에서 보정합니다.

GOOD TO KNOW

궁금한 점이 있나요?

한영타 변환에서 자주 묻는 내용을 정리했어요.

한영타 변환은 어떻게 동작하나요?

두벌식(표준) 키보드 배열을 기준으로 키 입력을 서로 매핑합니다. 자동 모드에서는 입력 문장의 한글·영문 비율을 비교해 변환 방향을 정합니다.

숫자나 특수문자도 변환되나요?

아니요. 숫자·공백·특수문자는 그대로 유지하고 한글·영문 키에 해당하는 문자만 변환합니다.

자동 감지가 반대로 나오면 어떻게 하나요?

입력창 위에서 영 → 한 또는 한 → 영 모드를 직접 선택해 주세요.
