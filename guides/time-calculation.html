자정을 넘는 시간, 어떻게 계산할까요?

자정을 넘으면 종료 날짜도 바꿔주세요

밤 10시 30분부터 새벽 1시 15분까지 작업했다면 먼저 날짜를 확인해야 합니다. 시각만 보면 종료 시각이 더 작지만, 실제로는 다음 날에 끝난 작업입니다. Toolify 시간 계산기는 시작과 종료를 날짜와 시각으로 입력하므로, 종료 날짜를 하루 뒤로 지정하면 됩니다.

입력 예시

시작: 2026년 9월 14일 22:30
종료: 2026년 9월 15일 01:15

결과: 2시간 45분 = 165분

직접 확인하려면 구간을 자정에서 나눠 보세요. 22:30에서 24:00까지 90분, 00:00에서 01:15까지 75분입니다. 두 구간을 더하면 165분입니다. 종료 날짜를 같은 날로 입력하면 계산기는 종료 시간이 시작 시간보다 앞이라는 안내를 표시합니다.

휴게시간은 전체 시간에서 한 번 빼세요

작업에 실제로 쓴 시간이 필요하다면 시작부터 종료까지의 경과 시간에서 쉬는 시간을 뺍니다. 예를 들어 09:00부터 18:00까지는 9시간이고, 그중 휴게가 60분이면 남는 시간은 8시간입니다.

입력 구간휴게휴게 제외
09:00 ~ 18:0060분8시간

쉬는 시간이 여러 번이었다면 먼저 합산해서 분 단위로 입력하세요. 10분씩 두 번, 30분 한 번 쉬었다면 합계는 50분입니다. 이미 휴게를 제외한 구간을 입력하고 다시 휴게를 빼면 시간이 이중으로 차감됩니다. 이 계산은 시간의 산술 계산이며, 임금이나 수당의 적용 여부는 판단하지 않습니다.

2시간 45분은 2.45시간이 아닙니다

시계는 60분을 한 시간으로 세지만 소수는 10진수입니다. 분을 소수 시간으로 바꾸려면 60으로 나눈 뒤 정수 시간에 더하세요. 2시간 45분은 2 + 45 ÷ 60 = 2.75시간입니다. 반대로 2.45시간은 소수 부분 0.45에 60을 곱한 27분을 더해 2시간 27분이 됩니다.

15분 = 0.25시간 · 30분 = 0.5시간 · 45분 = 0.75시간

총 분으로 바꾸기: 시간 × 60 + 분

일정표에 옮겨 적을 때는 2시간 45분처럼 단위를 함께 쓰세요. 소수 시간이 필요한 입력란에는 2.75를 넣으면 됩니다. 여러 구간을 더할 때는 먼저 분으로 통일하면 중간 반올림으로 생기는 오차를 줄일 수 있습니다.

Toolify에서 계산하는 순서

  1. 시간 계산기의 시간 차이 탭을 엽니다.
  2. 시작 날짜·시각과 종료 날짜·시각을 입력합니다. 자정을 넘었다면 종료 날짜를 확인합니다.
  3. 계산 결과를 확인합니다. 휴게를 제외하려면 근무시간 탭에서 휴게 분을 함께 입력합니다.

이 도구의 날짜·시각 입력은 현재 브라우저의 현지 시간대를 따릅니다. 서로 다른 나라의 시차를 자동으로 맞춰주는 입력이 아니므로 해외 일정은 같은 시간대로 맞춘 뒤 사용하세요. 일광절약시간 전환일에는 시계에 보이는 차이와 실제 경과 시간이 다를 수 있습니다.
